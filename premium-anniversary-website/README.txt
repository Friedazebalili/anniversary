PREMIUM ANNIVERSARY WEBSITE

FILES
- index.html
- styles.css
- script.js
- assets/anniversary-collage.png

HOW TO RUN
1. Keep all files and folders together.
2. Open index.html in a browser.
3. For deployment, upload the complete folder to your hosting provider.

CUSTOMIZE TEXT
Edit the headings and paragraphs inside index.html.

CUSTOMIZE COLORS
Edit the CSS variables at the top of styles.css.

REPLACE HERO IMAGE
Replace assets/anniversary-collage.png with another image using the same filename, or update the image path inside index.html.

LIBRARIES
GSAP, ScrollTrigger, and Lenis are loaded from CDNs, so an internet connection is required for animations and smooth scrolling.
